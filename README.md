# India Tropical Tracker

Interactive tropical-cyclone and low-pressure tracking application for the Indian Ocean and surrounding regions.

## Current Model Set

- ECMWF IFS HRES
- ECMWF IFS Ensemble (ENS)
- ECMWF AIFS Single
- NOAA/NCEP AI-GFS
- NOAA/NCEI OISST v2.1

## Features

- Automatic latest ECMWF cycle detection
- Tropical system track visualization
- Deterministic and ensemble track display
- AI-GFS MSLP-derived low-center tracking
- Sea-surface temperature overlay
- Forecast-hour selection
- Track playback
- Interactive map zoom
- PNG export
- Model-cycle availability display
